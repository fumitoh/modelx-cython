# Tutorial

This tutorial walks through cythonizing an exported modelx model with
`mx2cy`, using the `BasicTerm_S` model from
[lifelib](https://lifelib.io) as an example.  The same steps apply to any
modelx model.

## Step 1: Export the model from modelx

modelx-cython does not operate on live modelx models directly.  It operates
on models exported as pure-Python packages with modelx's
`Model.export` method.  Suppose `model` is a modelx Model:

```python
>>> import modelx as mx
>>> model = mx.read_model("BasicTerm_S")
>>> model.export("BasicTerm_S_nomx")
```

This creates a self-contained Python package named `BasicTerm_S_nomx` in the
current directory.  The exported package runs without modelx and is what
`mx2cy` takes as input.

## Step 2: Write a sample script

`mx2cy` needs to know the types of the parameters and values of the cells in
the model.  Instead of asking you to annotate the model, it *observes* the
types by running a sample script that you provide, while tracing every cells
call.

Create a file named `sample.py` in the directory that contains
`BasicTerm_S_nomx` (not inside it):

```python
from BasicTerm_S_nomx import BasicTerm_S

for i in range(1, 11):
    BasicTerm_S.Projection[i].pv_net_cf()
```

The sample script should exercise the model the same way your production
workload does:

* Call the cells you intend to call after compilation, so that their
  argument and return types are observed.
* Pass arguments spanning the ranges you will use.  For integer
  parameters, the largest observed value also determines the default size
  of the internal cache arrays (see {doc}`spec`).

Cells that the sample never reaches are left untyped and fall back to
generic `object` code, which still works but is not optimized.

## Step 3: Write a spec file (optional)

A *spec file*, named `spec.py` by default, supplies information that cannot
be observed from the sample run, such as the maximum sizes of cells
parameters, and lets you override inferred return types.  Place it next to
`sample.py`:

```python
{"spaces": {"Projection": {"cells_param_size": {"t": 241}}}}
```

This declares that the parameter `t` of the cells in the `Projection` space
takes values in `range(241)`, so a 241-element cache array is allocated per
cells.  See {doc}`spec` for the full format.

If you have no spec to provide, skip the file and pass `--no-spec` on the
command line.

## Step 4: Run mx2cy

In a Python-enabled command prompt or shell, change the current directory
with `cd` to where `BasicTerm_S_nomx` is located, and run:

```console
$ mx2cy BasicTerm_S_nomx
```

`mx2cy` then:

1. Copies `BasicTerm_S_nomx` to a new package `BasicTerm_S_nomx_cy`
   (an existing `BasicTerm_S_nomx_cy` is preserved as
   `BasicTerm_S_nomx_cy_BAK1`).
2. Runs `sample.py` against the original package while tracing calls to
   collect type information.
3. Rewrites the copied source files with Cython type annotations
   (in Cython's [pure Python
   mode](https://cython.readthedocs.io/en/latest/src/tutorial/pure.html))
   and generates a `.pxd` declaration file next to each module.
4. Writes a `setup.py` and compiles the package in place with
   `python setup.py build_ext --inplace`.

When the command finishes, the directory looks like this:

```text
.
├── BasicTerm_S_nomx/       # original exported model (untouched)
├── BasicTerm_S_nomx_cy/    # translated and compiled model
├── build/                  # compiler work files
├── sample.py
├── spec.py
└── setup.py                # generated by mx2cy
```

Use `--translate-only` to stop before compilation, or `--compile-only` to
re-run only the compilation of a previously translated package.  See
{doc}`cli` for all options.

## Step 5: Use the compiled model

The compiled package is a drop-in replacement for the exported one — only
the package name differs:

```python
from BasicTerm_S_nomx_cy import BasicTerm_S

result = BasicTerm_S.Projection[1].pv_net_cf()
```

You can compare the two packages to check consistency and measure the
speed-up:

```python
import timeit

from BasicTerm_S_nomx import BasicTerm_S as py_model
from BasicTerm_S_nomx_cy import BasicTerm_S as cy_model

assert py_model.Projection[1].pv_net_cf() == cy_model.Projection[1].pv_net_cf()

print(timeit.timeit(lambda: cy_model.Projection[1].pv_net_cf(), number=1))
```

```{note}
Like the exported pure-Python model, the compiled model caches computed
values.  To repeat a computation from scratch, re-import the package in a
fresh process.
```
